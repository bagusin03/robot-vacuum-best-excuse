The Cliff Sensor's Verdict: the funniest one-line excuse a robot vacuum gives for missing a spot, for the make.fun "The Robot Vacuum's Best Excuse" bounty. `main.ts` writes a single 121-character excuse to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> My cliff sensor called your dark rug a staircase, so I braked, beeped twice, and let the crumbs keep the place rent-free.

## Run it

```sh
node main.ts
```
